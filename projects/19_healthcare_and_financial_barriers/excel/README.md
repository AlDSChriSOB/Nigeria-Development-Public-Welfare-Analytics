# Excel workflow

analysis.xlsx is an actual Excel workbook generated by scripts/build_excel.mjs. If primary data is unavailable it contains an explicit missing-data status, input headers, and source/method notes, not invented values. For an executed preview it contains typed data, linked formulas and a trend chart. ImportAnalysis.pq refreshes SQL output in Excel through a separate Power Query import. After changing data, rerun the pipeline and workbook builder; the workbook does not refresh automatically.
