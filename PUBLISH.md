# Publish when GitHub permits repository creation

Create an empty public repository named Nigeria-Development-Public-Welfare-Analytics under AlDSChriSOB. From this directory:
```bash
git init
git add .
git commit -m "Add 20 Nigerian case-study workflows and six national previews"
git branch -M main
git remote add origin https://github.com/AlDSChriSOB/Nigeria-Development-Public-Welfare-Analytics.git
git push -u origin main
```
Do not force-push over existing work. The repository README accurately identifies unfinished primary-data and native BI work.
